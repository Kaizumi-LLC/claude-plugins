# Kaizumi tools by situation

Tool names are the Kaizumi connector's MCP tool names.

## Problem solving

| The user… | Tool |
| --- | --- |
| Talks through a problem loosely, or wants a one-page problem-solving report | `a3_report` |
| Has counts, minutes or costs by category and wants to know what matters most | `pareto_chart` |
| Wants to group possible causes (Method, Machine, Material, People, …) | `fishbone_diagram` |
| Wants to trace one problem back through successive "why"s | `five_whys` |

## Flow

| The user… | Tool |
| --- | --- |
| Describes steps from supplier to customer with cycle times, waits or inventory | `value_stream_map` |
| Wants to scope a process: suppliers, inputs, steps, outputs, customers | `sipoc_diagram` |
| Asks how fast the process must run to meet demand | `takt_time` |
| Wants the number of kanban cards or containers for a loop | `kanban_sizing` |
| Wants printable kanban cards for parts | `kanban_cards` |
| Wants to know how often a shared machine can run every part | `epei_calculator` |

## Standard work

| The user… | Tool |
| --- | --- |
| Explains how to do a job, or wants an SOP or TWI job breakdown | `work_instruction` |
| Has timed work elements over several cycles | `time_observation` |
| Wants to compare work per operator with takt, or balance a line | `yamazumi_chart` |
| Has one operator's manual, walk and machine times to check against takt | `standardized_work_combination_table` |
| Wants machine capacity per shift or the bottleneck step from manual and auto times | `process_capacity_sheet` |

## Equipment

| The user… | Tool |
| --- | --- |
| Gives planned time, downtime, cycle time and good/total counts | `oee` |
| Wants to size the gain from shorter changeovers | `smed_analysis` |

## Six Sigma

| The user… | Tool |
| --- | --- |
| Has readings in time order and asks whether the process changed | `control_chart` |
| Has measurements and specification limits and asks about Cp or Cpk | `process_capability` |
| Wants to list and rank ways a process can fail | `fmea` |
| Ran a crossed study and asks whether a gauge can be trusted | `gage_rr` |
| Has defects, units and opportunities and wants DPMO or a sigma level | `dpmo_sigma` |

## Don't use Kaizumi for

- Lean as in low-fat food or diets
- The Lean Startup method, or general explanations that need no chart or sheet
- Writing that has no process data, such as a poem about continuous improvement
